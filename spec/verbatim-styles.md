# Verbatim .docx Style Specification (interop spec for Cardstock)

Source of truth: `word/styles.xml` extracted from **`Debate.dotm`**, Verbatim 6.0.0,
cloned from https://github.com/ashtarcommunications/verbatim (path
`desktop/Debate.dotm`; byte-identical to `desktop/release/6.0.0/Debate.dotm`).
The raw file is preserved beside this spec as
a local extraction of `word/styles.xml` from Verbatim's `Debate.dotm`. That raw file is GPL-licensed and deliberately **not** committed to this MIT repo — this document records the factual properties needed for interoperability.

This document describes only the file format (OOXML style definitions and
direct-formatting conventions). All sizes marked "half-points" are the raw
`w:sz` values (OOXML `w:sz` is in half-points: `w:val="22"` = 11 pt).

## 0. Document defaults (`w:docDefaults`)

```xml
<w:docDefaults>
  <w:rPrDefault>
    <w:rPr>
      <w:rFonts w:asciiTheme="minorHAnsi" w:eastAsiaTheme="minorHAnsi"
                w:hAnsiTheme="minorHAnsi" w:cstheme="minorBidi"/>
      <w:sz w:val="22"/>
      <w:szCs w:val="22"/>
      <w:lang w:val="en-US" w:eastAsia="en-US" w:bidi="ar-SA"/>
    </w:rPr>
  </w:rPrDefault>
  <w:pPrDefault>
    <w:pPr>
      <w:spacing w:after="160" w:line="259" w:lineRule="auto"/>
    </w:pPr>
  </w:pPrDefault>
</w:docDefaults>
```

Default run size is **22 half-points (11 pt)**; default paragraph spacing is
160 twips after, line 259 auto (Word's "1.08" multiple). All styles below
inherit from these defaults unless they override.

## 1. Style mapping table

| Debate concept | styleId | `w:name` | Alias(es) (`w:aliases`) | Type | basedOn | Outline level (`w:outlineLvl`, 0-based) | Size (half-pt / pt) |
|---|---|---|---|---|---|---|---|
| Pocket | `Heading1` | `heading 1` | `Pocket` | paragraph | `Normal` | 0 | 52 / 26 pt |
| Hat | `Heading2` | `heading 2` | `Hat` | paragraph | `Normal` | 1 | 44 / 22 pt |
| Block | `Heading3` | `heading 3` | `Block` | paragraph | `Normal` | 2 | 32 / 16 pt |
| Tag | `Heading4` | `heading 4` | `Tag` | paragraph | `Normal` | 3 | 26 / 13 pt |
| Card body / normal text | `Normal` | `Normal` | `Normal/Card` | paragraph (default) | — | body text (none) | inherits 22 / 11 pt |
| Cite (author + date) | `Style13ptBold` | `Style 13 pt Bold` | `Cite` | character | `DefaultParagraphFont` | — | 26 / 13 pt |
| Underline | `StyleUnderline` | `Style Underline` | `Underline` | character | `DefaultParagraphFont` | — | 22 / 11 pt |
| Emphasis | `Emphasis` | `Emphasis` | — | character | `DefaultParagraphFont` | — | 22 / 11 pt |
| Hyperlink | `Hyperlink` | `Hyperlink` | — | character | `DefaultParagraphFont` | — | inherits |

Linked character variants (auto-generated by Word for the linked heading
styles, `w:link` pairs): `Heading1Char` ("Heading 1 Char", alias "Pocket
Char"), `Heading2Char` ("Hat Char"), `Heading3Char` ("Block Char"),
`Heading4Char` ("Tag Char"). They mirror the run properties of their
paragraph styles and appear when a heading style is applied to a sub-range of
a paragraph.

Important interop notes:

- **Verbatim's VBA addresses styles by alias** (`Styles.Item("Pocket")`,
  `"Hat"`, `"Block"`, `"Tag"`, `"Cite"`, `"Underline"`, `"Emphasis"`,
  `"Normal"`). In the XML, the alias lives in `w:aliases` and Word's UI shows
  the combined local name (e.g. "Heading 1,Pocket"). Cardstock should match on
  **styleId first**, and fall back to `w:name`/`w:aliases` for documents
  produced by other tools.
- **Styles that do NOT exist in stock Verbatim 6.0.0:** there is no
  `Analytic`, `Undertag`, `Card`, or `Citation` style. "Card" exists only as
  part of the alias of Normal (`Normal/Card`); "Analytic" appears only in a
  compatibility macro (`Formatting.ConvertAnalyticsToTags`) that converts
  paragraphs whose style name *starts with* "analytic" (produced by other
  paperless templates) into `Tag`. Cardstock may accept an incoming
  `Analytic*` style as a Tag-equivalent but must not emit one.
- Outline levels drive Verbatim's navigation/"Send to Speech" logic: Pocket=1,
  Hat=2, Block=3, Tag=4 (1-based, `w:outlineLvl` 0–3). Card text is body text.

## 2. Paragraph styles — exact XML

### 2.1 Normal ("Normal/Card")

```xml
<w:style w:type="paragraph" w:default="1" w:styleId="Normal">
  <w:name w:val="Normal"/>
  <w:aliases w:val="Normal/Card"/>
  <w:uiPriority w:val="5"/>
  <w:qFormat/>
  <w:rsid w:val="00FE5699"/>
  <w:rPr>
    <w:rFonts w:ascii="Calibri" w:hAnsi="Calibri" w:cs="Calibri"/>
  </w:rPr>
</w:style>
```

Font Calibri; size inherited from docDefaults (22 half-pt = 11 pt); paragraph
spacing inherited (after 160, line 259 auto). No pPr overrides.

### 2.2 Heading1 ("heading 1" / Pocket)

```xml
<w:style w:type="paragraph" w:styleId="Heading1">
  <w:name w:val="heading 1"/>
  <w:aliases w:val="Pocket"/>
  <w:basedOn w:val="Normal"/>
  <w:next w:val="Normal"/>
  <w:link w:val="Heading1Char"/>
  <w:qFormat/>
  <w:rsid w:val="00FE5699"/>
  <w:pPr>
    <w:keepNext/>
    <w:keepLines/>
    <w:pageBreakBefore/>
    <w:pBdr>
      <w:top w:val="single" w:sz="24" w:space="1" w:color="auto"/>
      <w:left w:val="single" w:sz="24" w:space="4" w:color="auto"/>
      <w:bottom w:val="single" w:sz="24" w:space="1" w:color="auto"/>
      <w:right w:val="single" w:sz="24" w:space="4" w:color="auto"/>
    </w:pBdr>
    <w:spacing w:before="240" w:after="0"/>
    <w:jc w:val="center"/>
    <w:outlineLvl w:val="0"/>
  </w:pPr>
  <w:rPr>
    <w:rFonts w:eastAsiaTheme="majorEastAsia" w:cstheme="majorBidi"/>
    <w:b/>
    <w:sz w:val="52"/>
    <w:szCs w:val="32"/>
  </w:rPr>
</w:style>
```

Summary: Calibri (via Normal) 26 pt bold, centered, boxed with a 3 pt
(`w:sz="24"` eighth-points) single border on all four sides, page break
before, keepNext+keepLines, spacing before 240 / after 0, outline level 0.
Not underlined.

Same visible size/weight as the Cite character style — a Tag is a paragraph,
a Cite is a run inside a Normal paragraph.

## 3. Character styles — exact XML

### 3.1 Style13ptBold ("Style 13 pt Bold" / Cite)

```xml
<w:style w:type="character" w:customStyle="1" w:styleId="Style13ptBold">
  <w:name w:val="Style 13 pt Bold"/>
  <w:aliases w:val="Cite"/>
  <w:basedOn w:val="DefaultParagraphFont"/>
  <w:uiPriority w:val="6"/>
  <w:qFormat/>
  <w:rsid w:val="00FE5699"/>
  <w:rPr>
    <w:b/>
    <w:bCs/>
    <w:sz w:val="26"/>
    <w:u w:val="none"/>
  </w:rPr>
</w:style>
```

Bold, 13 pt, explicitly not underlined (`w:u w:val="none"` — so applying Cite
over underlined text kills the underline). This is the author-name + year run
at the start of a cite paragraph. The rest of the cite (full citation detail)
is typically plain Normal-sized text in the same paragraph.

### 3.2 StyleUnderline ("Style Underline" / Underline)

```xml
<w:style w:type="character" w:customStyle="1" w:styleId="StyleUnderline">
  <w:name w:val="Style Underline"/>
  <w:aliases w:val="Underline"/>
  <w:basedOn w:val="DefaultParagraphFont"/>
  <w:uiPriority w:val="7"/>
  <w:qFormat/>
  <w:rsid w:val="00FE5699"/>
  <w:rPr>
    <w:b w:val="0"/>
    <w:sz w:val="22"/>
    <w:u w:val="single"/>
  </w:rPr>
</w:style>
```

Single underline, 11 pt, explicitly **not bold** (`w:b w:val="0"`). This is
the style Verbatim's underline shortcut applies to card text a debater will
read. Note: some documents in the wild use direct `<w:u w:val="single"/>`
run formatting instead of this character style — Cardstock must treat both
as "underlined."

### 3.3 Emphasis (built-in name, redefined)

```xml
<w:style w:type="character" w:styleId="Emphasis">
  <w:name w:val="Emphasis"/>
  <w:basedOn w:val="DefaultParagraphFont"/>
  <w:uiPriority w:val="8"/>
  <w:qFormat/>
  <w:rsid w:val="00FE5699"/>
  <w:rPr>
    <w:rFonts w:ascii="Calibri" w:hAnsi="Calibri" w:cs="Calibri"/>
    <w:b/>
    <w:i w:val="0"/>
    <w:iCs/>
    <w:sz w:val="22"/>
    <w:u w:val="single"/>
    <w:bdr w:val="none" w:sz="0" w:space="0" w:color="auto"/>
  </w:rPr>
</w:style>
```

Verbatim redefines Word's built-in Emphasis: **bold + single underline, 11 pt,
explicitly NOT italic** (`w:i w:val="0"`), no text border. Used for the most
important words inside underlined card text. Do not assume Emphasis = italic.

### 3.4 Hyperlink

```xml
<w:style w:type="character" w:styleId="Hyperlink">
  <w:name w:val="Hyperlink"/>
  <w:basedOn w:val="DefaultParagraphFont"/>
  <w:uiPriority w:val="99"/>
  <w:unhideWhenUsed/>
  <w:rsid w:val="00D839C5"/>
  <w:rPr>
    <w:color w:val="0563C1" w:themeColor="hyperlink"/>
    <w:u w:val="single"/>
  </w:rPr>
</w:style>
```

Also present: `FollowedHyperlink` is redefined to `color auto`, `u none`
(Verbatim deliberately makes followed links look like plain text).

## 4. Direct-formatting conventions (not styles)

### 4.1 Highlighting

Highlighting is **direct run formatting** (`w:rPr/w:highlight`), never a
character style. Verbatim's Highlight macro calls `WordBasic.Highlight`,
i.e. Word's current highlighter color; the shipped default and the color
Verbatim's auto-formatting applies is **yellow** (`wdYellow`,
`<w:highlight w:val="yellow"/>`).

Verbatim's settings UI enumerates the full Word highlighter palette
(`HighlightColorToEnum` in `Formatting.bas`); the corresponding OOXML
`w:highlight` values Cardstock must round-trip:

| Verbatim UI name | WdColorIndex | OOXML `w:highlight` value |
|---|---|---|
| Yellow (default) | wdYellow | `yellow` |
| Bright Green | wdBrightGreen | `green` |
| Turquoise | wdTurquoise | `cyan` |
| Pink | wdPink | `magenta` |
| Blue | wdBlue | `blue` |
| Red | wdRed | `red` |
| Dark Blue | wdDarkBlue | `darkBlue` |
| Teal | wdTeal | `darkCyan` |
| Green | wdGreen | `darkGreen` |
| Violet | wdViolet | `darkMagenta` |
| Dark Red | wdDarkRed | `darkRed` |
| Dark Yellow | wdDarkYellow | `darkYellow` |
| Light Gray | wdGray25 | `lightGray` |
| Dark Gray | wdGray50 | `darkGray` |
| Black | wdBlack | `black` |
| White | wdWhite | `white` |
| None | wdNoHighlight | (attribute absent / `none`) |

Beware the trap: Word's "Bright Green" highlighter is OOXML `green`, and
Word's "Green" is OOXML `darkGreen`; "Turquoise" is `cyan`, "Pink" is
`magenta`.

Highlighted runs in practice are always also underlined (highlighting marks
the subset of the underlined text that gets read); Cardstock should not rely
on that invariant when parsing, but should preserve it when emitting.

### 4.2 Shrunk / minimized ("condensed") text

Un-underlined card text that the debater will not read is minimized by
Verbatim's Shrink macro (`Shrink.bas`) as **direct font-size formatting** —
there is no character style for it:

- First shrink sets all non-underlined, non-bold text in the card to
  **8 pt** (`<w:sz w:val="16"/>`).
- Repeated invocations cycle **8 → 7 → 6 → 5 → 4 → back to Normal (11 pt)**.
- Mixed sizes in a card normalize to 8 pt.
- Underlined and bold runs are left at 11 pt.
- Paragraph marks/pilcrows inside shrunk cards are set to **6 pt**,
  un-underlined, un-bolded (`ShrinkPilcrows`).
- `UnshrinkAll` resets all non-underlined, non-bold body-text runs to the
  Normal style's size (11 pt).

Cardstock convention: treat any run in a card body with `w:sz` ≤ 16
half-points (8 pt) and no underline as "minimized" text; emit minimized text
at exactly `w:sz w:val="16"` (8 pt).

## 5. Not present in stock Verbatim

For explicitness, stock Verbatim 6.0.0 defines **no**:

- `Analytic` style (legacy import concept only; `ConvertAnalyticsToTags`
  rewrites any incoming style named `analytic*` to Tag)
- `Undertag` style
- standalone `Card` paragraph style (card body is `Normal`, alias
  "Normal/Card")
- `Citation` style (the cite character style is `Style13ptBold`, alias "Cite")
- debate-specific Heading 5–9 (Heading5 exists but is the untouched stock
  Word definition, semiHidden, and carries no debate meaning)
